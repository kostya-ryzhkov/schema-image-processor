# schema-image-processor
Transforming images of a schema into a csv file.

# Instructions
Dump standardized screenshots of the schema you would like to process into src/2-data. **Note that the processor is currently setup for the photos I was using, you will most likely need to adjust the parameters of the image processing to make it work for a different table.**

# Dependencies
requiremnents.txt has all of the necessary libraries for this project to run.
